AI-focused Flox environments and packages, curated for reproducibility. This category covers everything an AI-first dev needs: coding agents like Claude Code and Codex, local LLM runtimes such as Ollama, retrieval-augmented generation stacks (LangChain, Verba, pgvector via the PostgreSQL env), and the orchestration layers and skills that compose them. Every entry installs with a single manifest line and is pinned by Nix for stable, hermetic builds.
